# Sales Data Analysis System

## Overview
Developed a Sales Data Analysis System using Python, SQL (SQLite), and Pandas to analyze sales data and generate meaningful business insights.

## Features & Technical Implementation
- **Database Design (`setup_database.py`)**: Relational database with `customers`, `products`, `orders`, and `order_items` tables.
- **SQL Analytics (`sql_analysis.py`)**: Implemented SQL queries using `JOIN`, `SUM`, `COUNT`, `ROUND`, and `GROUP BY` to analyze product revenue and customer purchasing patterns.
- **Data Cleaning & Visualization (`visualize_sales.py`)**: Utilized Pandas for data cleaning, net revenue calculation, and date formatting, and Matplotlib/Seaborn to export visual reports (`top_products.png` and `monthly_sales_trend.png`).

## Key Insights Generated
- **Total Revenue**: $1,469.00
- **Total Units Sold**: 28
- **Top-Performing Product**: Mechanical Keyboard ($501.50)
